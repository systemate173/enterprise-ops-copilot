# RBK-CS-PAYMENTS-010 – Payment Processing Failures

## Symptoms
- Customer checkout failures
- Charges declined or stuck pending
- Errors returned by payment provider

## Initial Checks
- Verify payment provider status
- Collect failing transaction IDs and timestamps
- Check recent billing-related changes

## Resolution Steps
- Retry failed transactions if safe
- Disable affected payment method temporarily
- Coordinate with payment provider support

## Escalation
- Escalate to Finance or Payments Engineering

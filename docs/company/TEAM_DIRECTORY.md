# TEAM_DIRECTORY

## On-Call / Owners
- IT Ops On-Call: handles VPN, DNS, login access, employee tooling incidents
- IAM/Security: handles SSO/IDP, auth policies, certificates, RBAC/permissions incidents
- Network: handles routing, firewall, VPN gateways, connectivity issues

- Platform: handles CI/CD, deploy tooling, shared services used by product teams
- SRE: handles reliability, performance, scaling, monitoring, incident coordination
- Mobile: handles iOS/Android app releases, mobile crashes, app store rollbacks
- Frontend: handles web UI, browser-specific issues, frontend deployments

- Payments Engineering: handles payment provider integration, checkout failures, refund processing
- Finance: handles reconciliation, chargebacks, payout/refund escalations

- Warehouse Ops: handles WMS, label printing, packing/shipping workflows
- Logistics Ops: handles delivery routes, dispatch, fleet coordination
- Operations Lead: handles cross-team operational decisions and customer-impacting ops issues

- Customer Support Lead: handles customer comms, ticket triage, support workflows
- Engineering On-Call: handles engineering escalation when owner unclear
